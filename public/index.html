快捷键与归桶规则说明

1 设为 神图（再按取消）
2 设为 心动（再按取消）

H 叠加/取消 修手指
F 叠加/取消 修脚
O 叠加/取消 其他局部修复
R 叠加/取消 同提示词重抽
N 打开 文本/语音备注
← → 切换上一张 / 下一张
Enter / 双击 打开原分辨率缩放灯箱
单图唯一归桶互斥优先级（Rule 3）：
  1. 含 H / F / O 任一修复标记 → 待修复 (repair)（同时完整保留已选档位供复审参考，如「待修复 (原定1档)」）
  2. 否则含 R 标记 → 待重抽 (redraw)
  3. 否则档位为 1 / 2 / 3 → 拟归档 (archived)
  4. 其余（未定档且无标记） → 不收录 (discarded)
