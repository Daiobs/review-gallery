审图备注

四档星级快捷键与正交分流规则

1 ★★★ 神图 / 核心锚（tier=3，再按取消）
2 ★★ 心动 / 优质锚（tier=2，再按取消）
3 ★ 高品质 / 达标锚（tier=1，再按取消）
4 ☆ 收藏 / 留样（tier=0，再按取消）
H 叠加/取消 修手指（转为待修复）
F 叠加/取消 修脚（转为待修复）
O 叠加/取消 其他局部修复（转为待修复）
R 叠加/取消 旁路重抽（不改变原图主去向）
N 打开 文本/语音备注
← → 切换上一张 / 下一张
Enter / 双击 打开原分辨率缩放灯箱
0（灯箱内） 重置为 适应屏幕 缩放
单图结论正交规则（主去向 destination × 旁路重抽 redraw）：
  1. 含 H / F / O 任一修复标记 → 主去向 待修复 (repair)（同时完整保留已打星级作为意向档，如「待修复(意向★★★) · H」）
  2. 否则已打星级（tier ∈ {3, 2, 1, 0}） → 主去向 拟归档 (archive)
  3. 其余（未打星级且无修复标记） → 主去向 不收录 (discard)
  4. 独立旁路 R（重抽）：与上述三类主去向完全正交叠加——★★★ + R 既进「拟归档」又进「待重抽」；仅 R 原图不收录并生成重抽待办（「仅重抽（原图不收）」）。
